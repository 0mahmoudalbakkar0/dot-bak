# Changelog

## 1.1.8 – first public release
- Radial extension wheel for Windows Explorer and the desktop, opened by pressing and holding the middle mouse button (or a side button).
- Rich default extension lists for the most common conversions (`.txt` → `.py`, `.json`, `.md`, `.csv`, `.html`, ...).
- Configurable wheel button and keyboard shortcuts (defaults: middle button, `Ctrl+Alt+E`, `Ctrl+Alt+Z`).
- Auto-select toggle (select the file under the cursor automatically, or require selecting it first).
- Arabic and English interface with automatic Windows-language detection on first run; layout mirrors for Arabic.
- Save button with clear confirmation (changes are also saved automatically).
- Smart content detection, danger/mismatch warnings, `.bak` backup and restore, undo history.
- "Report a problem" button (Telegram) and About page with author links.
